# 📦 Sipariş ve Stok Yönetimi

Modern bir satın alma, stok ve üretim takip sistemi.

## 🚀 Teknolojiler

- **Frontend:** React, Vite, TailwindCSS, React Router, Axios, Recharts, Lucide Icons
- **Backend:** Node.js, Express, MongoDB, Mongoose, JWT, Bcrypt
- **Veritabanı:** MongoDB Atlas

## ✨ Özellikler

- 🔐 Kullanıcı girişi ve rol yönetimi
- 📦 Ürün kartları yönetimi
- 🏢 Tedarikçi yönetimi
- 📋 Satın alma talepleri
- 🔄 Stok hareketleri (giriş/çıkış/transfer/sayım/hurda)
- 👥 Kullanıcı yönetimi (admin paneli)
- 📊 Dashboard ve raporlar
